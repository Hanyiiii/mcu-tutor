# 芯师傅 ChipMaster · 演示视频脚本（约 5 分钟）

> 用途：参赛作品演示视频 / 现场路演备用。录屏工具可用 OBS、EV 录屏或系统自带录屏，推荐 1080P 横屏 + 画外音（或现场口述）。

## 一、开场（0:00 – 0:40）

**画面**：浏览器打开 https://hanyiiii.github.io/mcu-tutor/ 首页全景

**口播**：
「各位评委老师好。我们是【学校名称】【团队名称】团队，参赛作品是——芯师傅 ChipMaster，一款面向单片机初学者的 AI 学习助手，属于 AI 创意赛道教育场景应用。

单片机课程是电类专业核心课，但同学们普遍遇到三大痛点：概念零散没人随时问、代码不会写例程看不懂、Proteus 仿真搭不出电路不运行。芯师傅的答案，就是把大模型能力装进单片机教学最吃力的环节里。」

## 二、功能演示一：AI 智能答疑（0:40 – 1:50）

**画面**：点击左侧「AI 答疑」，点击快捷提问「Keil 报错 C202 是什么意思？」

**口播**：
「首先是 AI 智能答疑。注意右下角的提示——提问后，系统先在内置知识库中检索，命中了 3 条相关资料，自动注入大模型上下文，所以回答是贴合教学场景的，而不是泛泛而谈。

再来个开放式问题：流水灯怎么写？（打字输入并发送）可以看到回答是流式输出的，代码块完整、带注释，可以直接复制进 Keil 编译。」

## 三、功能演示二：代码生成（1:50 – 2:50）

**画面**：切到「代码生成」页，先切换几个模板（电子时钟），再演示 AI 生成（勾选外设「定时器」「LED」，点 AI 生成）

**口播**：
「第二个模块是代码生成。这里内置 13 个经典模板，全部经过 Keil 编译验证——比如这个数码管电子时钟，定时器 50ms 中断精确计时、动态扫描显示，下载成 .c 文件就能直接编译。

也可以按需求定制：勾选外设组合，让 AI 现场生成。左侧还附了 Keil 编译检查清单，帮新手自查常见错误。」

## 四、功能演示三：仿真向导（2:50 – 3:50）

**画面**：切到「仿真向导」，展开「51 最小系统」和「LED 流水灯电路」，点「查看配套代码」跳转

**口播**：
「第三个模块是 Proteus 仿真向导。8 大常用电路，每个都给出元件库名、接线步骤和避坑提示——比如最小系统要接晶振和复位电路、流水灯的 LED 要用低电平点亮接法。搭完电路点这里，直接跳到配套代码，形成『电路 + 程序』闭环。」

## 五、知识库与学习路径（3:50 – 4:30）

**画面**：切到「知识库」搜索「定时器」；再切「学习路径」勾选一项任务

**口播**：
「知识库收录了 37 条核心知识点，支持分类浏览和搜索，它同时也是 AI 答疑的知识来源。

学习路径是四阶段进阶路线，从 C 语言基础到 STM32 入门，20 项任务，进度保存在本地，学生可以按图索骥、闯关式学习。」

## 六、技术与价值（4:30 – 5:10）

**画面**：回到首页，滚动展示；或切到 PPT 的架构页

**口播**：
「技术上，前端用 Vue 3 部署在 GitHub Pages，后端用 Supabase Edge Function 代理大模型接口，密钥不进前端，当前接入 DeepSeek，可无缝切换国内主流大模型。整套系统零服务器成本，开发阶段 API 费用仅十多元。

我们的愿景是：让每个单片机学习者，都有一位随时在线的 AI 私教。谢谢各位评委老师！」

## 录制提示

- 录屏前清空 AI 答疑对话历史（刷新页面即可），保证画面干净
- 若现场无网络，可提前录制离线版本（本地 npm run dev + npm run server）
- 建议先按脚本试录一遍，掐点控制在 5 分钟内
- 视频命名建议：`芯师傅ChipMaster演示视频_【学校】_【团队】.mp4`
